# Onboarding Lab 1 — Register and Authenticate an Agent

Steps:
1. Start the dashboard: `streamlit run app.py`
2. Go to **Register Agent** and create a demo agent with a mock credential.
3. Use the `agent_identity` helper to generate keys and verify the agent appears in the registry.
4. Attempt authentication using the agent's credential and observe the audit log.

Expected outcome: agent registered, authentication logged, and trust score available in Health Center.
