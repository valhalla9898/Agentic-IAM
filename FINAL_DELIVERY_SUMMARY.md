## 📦 INSTALLATION & USAGE

### Quick Start
```bash
# 1. Clone
git clone https://github.com/valhalla9898/Agentic-IAM.git

# 2. Setup
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 3. Run (2 terminals)
# Terminal 1:
uvicorn api.app:app --port 9000

# Terminal 2:
streamlit run app.py --port 8501

# 4. Access
# Dashboard: http://127.0.0.1:8501
# API Docs: http://127.0.0.1:9000/docs
# GraphQL: http://127.0.0.1:9000/graphql
```

### Docker
```bash
docker-compose up -d
```

### Kubernetes
```bash
kubectl apply -f k8s/
```
